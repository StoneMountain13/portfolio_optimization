# 03｜Boyd 等（2017）：多周期凸优化交易

## 一句话理解

组合管理不是每天重新做一遍“无摩擦 Markowitz”，而是在预期收益、风险、交易成本和未来调仓机会之间做动态权衡。

## 从“选权重”升级为“选交易”

令 $w_t$ 为第 $t$ 期持仓权重，$z_t=w_t-w_{t-1}$ 为交易。一个简化的多期目标是：

$$
\max_{z_1,\ldots,z_H}
\sum_{t=1}^{H}
\left(
\hat r_t^\top w_t
-\frac{\gamma}{2}w_t^\top\Sigma_t w_t
-C_t(z_t)
-H_t(w_t)
\right).
$$

其中：

- $\hat r_t$：预测收益；
- $\Sigma_t$：风险模型；
- $C_t(z_t)$：点差、手续费和市场冲击；
- $H_t(w_t)$：借券费等持仓成本；
- $H$：规划期数。

多周期优化得到一整条交易计划，但现实中通常只执行第一步。下一期拿到新数据和新预测后重新求解，这就是滚动时域/模型预测控制思想。

## 为什么未来计划会改变今天的交易

假设模型预测某资产本月有 alpha、下月 alpha 消失：

- 单周期优化可能今天大买；
- 多周期优化知道下月还要卖出，会提前计入两次交易成本；
- 因而今天的仓位可能更克制。

反过来，如果未来多个时期 alpha 持续，优化器更愿意支付一次建仓成本。

## 代码做了什么

`multi_period_demo.py` 使用五个资产、四个月预测期，比较：

- Myopic/SPO：只看第一个月的单周期策略；
- MPO：同时规划未来四个月，但现实中只执行第一笔交易。

交易被拆成非负买入量 $z^+$ 和卖出量 $z^-$：

$$
z=z^+-z^-,\qquad |z|=z^++z^-.
$$

这样可以在没有专用凸优化软件的情况下，用 SciPy 清晰演示线性交易成本、二次冲击、个股上限和换手上限。

## 代码与原论文的差别

为了适合初学者，本例：

- 使用小规模确定性参数，而不是连接行情数据库；
- 只做长仓，未加入借券成本；
- 使用线性成本 + 二次冲击的简化模型；
- 用 SciPy SLSQP 求解拆分后的光滑约束问题，而不是 CVXPY。

数学思想与论文一致，但不是 CVXPortfolio 的替代品。做完本例后，再看论文配套库会轻松许多。

## 实盘最容易踩的坑

- 用未来信息生成历史时点的预测或风险模型，即前视偏差；
- 优化成本和回测成交成本使用两套不一致参数；
- 把远期预测当作和近端预测同样可靠；
- 求解器返回 `success` 就认为组合可交易，没有复核约束残差；
- 忽略成交量、停牌、涨跌停、最小交易单位和资产退市。
