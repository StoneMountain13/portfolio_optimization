# 数据字典

## `sample_universe.csv`

| 字段 | 含义 | 典型单位 |
|---|---|---|
| `ticker` | 证券代码 | 文本 |
| `sector` | 行业分类 | 文本 |
| `benchmark_weight` | 基准组合权重 | 0–1 |
| `current_weight` | 调仓前权重 | 0–1 |
| `alpha_annual` | 模型预测的年化主动收益 | 小数，如 0.02=2% |
| `adv_usd` | 日均成交额 | 美元 |
| `cost_bps` | 线性单边交易成本假设 | 基点 |
| `beta` | 市场 Beta 风险暴露 | 标准化/模型单位 |
| `size` | 规模暴露 | 标准化分数 |
| `value` | 价值暴露 | 标准化分数 |
| `momentum` | 动量暴露 | 标准化分数 |
| `quality` | 质量暴露 | 标准化分数 |
| `specific_vol_annual` | 年化特异波动率 | 小数 |

## `factor_covariance.csv`

五个风险因子年化收益的协方差矩阵。行列名称必须与代码中的 `FACTOR_NAMES` 完全一致。

## 替换成真实数据前

1. 所有输入必须是决策时点可获得的 point-in-time 数据；
2. 财报因子要使用真实发布日期，而不是报告期末日期；
3. 对停牌、退市、上市未满窗口和缺失值制定规则；
4. 保证 alpha、协方差和成本使用相容的时间单位；
5. 风险因子暴露若做标准化，训练期和交易期必须使用相同定义；
6. ADV、点差和冲击参数应使用与策略执行期限一致的估计窗口；
7. 在送入优化器前检查权重和为 1、协方差对称与半正定、证券顺序对齐。
