# 业界风格的量化组合优化：从 Alpha 到可交易组合

这是一个面向初学者、但尽量遵循资产管理行业工作方式的可运行教学项目。它不依赖行情 API：代码会生成一份**有隐藏真实结构的合成股票市场**，让你能清楚检验 PCA 与 Barra 风格风险模型、成本与约束对优化结果的影响。

> 重要边界：本项目用于研究和学习，不构成投资建议。真实生产系统还要处理复权、停牌、幸存者偏差、公司行动、交易规则、税费、容量和模型治理。

## 你将学到什么

完整流程是：

```text
股票池与数据清洗
  -> alpha（预期超额收益）
  -> 风险模型（PCA 或 Barra 风格基本面模型）
  -> 交易成本/流动性模型
  -> 约束（基准、行业、风格、单票、换手、预算）
  -> 优化器
  -> 可交易权重与交易单
  -> 独立约束检查、风险归因、事后评估
```

## 快速开始

建议 Python 3.10+。在本目录运行：

```bash
python -m pip install -r requirements.txt
python run_pipeline.py
```

也可切换风险模型：

```bash
python run_pipeline.py --risk-model pca
python run_pipeline.py --risk-model barra
```

脚本会生成 `outputs/` 中的 CSV、图和 `model_comparison.csv`。默认使用 **Barra 风格风险模型**，因为它的可解释性与风险预算方式更接近主动权益组合管理实践。

## 文件导览

- `docs/00_全流程总览.md`：先读这个，理解每一个输入如何进入优化器。
- `docs/01_Alpha与预测.md`：收益预测的作用与“预测/风险分离”。
- `docs/02_PCA风险模型教材.md`：从协方差、特征分解到低秩协方差和组合风险。
- `docs/03_Barra风格风险模型教材.md`：风格、行业、因子收益回归、因子协方差、特异风险。
- `docs/04_优化器与约束.md`：目标函数、成本、约束，以及为何必须独立验算。
- `docs/05_生产化与回测.md`：生产系统、回测与归因的关键防错点。
- `src/`：代码；每个模块有中文注释并可以单独阅读。
- `data/`：运行后生成的合成截面与收益率数据。
- `outputs/`：运行结果。

## 最建议的学习顺序

1. 读 `docs/00_全流程总览.md` 与 `docs/04_优化器与约束.md`；
2. 跑一遍默认 Barra 版本，打开 `outputs/portfolio_report.csv`；
3. 跑 PCA 版本，比较 `outputs/model_comparison.csv`；
4. 回到两份风险模型教材，逐行阅读对应代码；
5. 将合成 `alpha` 改成你自己的多因子预测，再逐步加入现实约束。
