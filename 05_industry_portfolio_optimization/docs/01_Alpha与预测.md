# 1. Alpha：优化器相信的收益预测

## 1.1 Alpha 是什么，不是什么

在组合优化中，$\alpha_i$ 是股票 $i$ 的**预期主动收益**，不是历史收益，也不是某个因子暴露本身。例如你的模型认为未来一个月 A 股票相对基准多赚 1%，就可令 $\alpha_A=1\%$。

Alpha 的质量通常由 rank IC、ICIR、分层收益、稳定性、容量和交易成本后的收益来评价；不能只看训练集 $R^2$。

## 1.2 业界常见的 alpha 处理

原始预测进入优化器前经常会：

1. 对极端值做 winsorize，避免一个异常样本主导组合；
2. 截面标准化，统一量纲；
3. 对行业、市值等已知暴露做中性化，避免把“行业 beta”误当成个股 alpha；
4. 以模型置信度、预测半衰期、数据新鲜度缩放；
5. 与上一期 alpha 做平滑，降低噪声驱动的换手。

本项目 `build_alpha()` 使用价值、动量、质量和微小残差构造一份教学 alpha。合成市场中的真实未来收益确实由这些风格部分驱动，因此可以演示流程，但**不能把这个合成结果理解成真实可盈利策略**。

## 1.3 不确定性应该进入哪里？

最简单是缩小 alpha：$\tilde\alpha=k\alpha, 0<k<1$。更进一步可为每只股票给不同置信度 $k_i$，或把预测误差加入鲁棒优化。实践中，如果 alpha 过度自信，优化器的结果往往表现为：高度集中、换手很高、样本外快速失效。

## 1.4 检验清单

- 标签是否严格在预测时点之后？是否存在未来函数？
- 横截面是否包含退市股票，避免幸存者偏差？
- 是否用点时（point-in-time）财务数据？
- 预测收益减去成本后还有统计显著性吗？
- Alpha 是否与风险模型因子高度重合？如果重合，是有意承担还是无意暴露？
