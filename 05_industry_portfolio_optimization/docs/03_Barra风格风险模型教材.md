# 3. Barra 风格基本面风险模型教材

## 3.1 模型结构

Barra 风格模型的核心不是某个商业软件，而是一个可解释的横截面因子模型。对第 $t$ 期、股票 $i$：

$$
r_{i,t}=\sum_{k=1}^K X_{i,k,t}f_{k,t}+u_{i,t}.
$$

- $X$：股票已知的因子暴露（风格 + 行业）；
- $f_t$：当期因子收益；
- $u_t$：特异收益。

在某个时点，组合的协方差写作：

$$
\Sigma=XFX^T+D,
$$

其中 $F=\mathrm{Cov}(f_t)$，$D=\mathrm{diag}(\sigma^2_{u,i})$。对主动权重 $x$，组合风险分解为：

$$
x^T\Sigma x=(X^Tx)^TF(X^Tx)+\sum_i x_i^2\sigma^2_{u,i}.
$$

这使得“行业偏离多少、价值/动量押注多少、因子风险贡献多少”都可以报告与约束。

## 3.2 因子暴露如何构造？

**风格因子**通常由多个描述子合成，例如：

| 风格 | 可能描述子（示意） |
|---|---|
| Size | $\log$(自由流通市值) |
| Value | B/P、E/P、CF/P |
| Momentum | 过去 12-1 月收益，常跳过最近一个月 |
| Volatility | 历史波动率、beta、残差波动 |
| Liquidity | 换手、ADV、交易天数 |
| Quality | ROE、杠杆、盈利稳定性 |

描述子会经历点时化、异常值处理、行业/国家中性化、标准化、缺失值填补和权重合成。行业因子通常是一组 one-hot 虚拟变量；为了避免完全共线，需要省略一个行业、加约束或采用特定加权回归处理。

本项目为教学简化：使用 size/value/momentum/quality 四个 z-score 风格暴露和 three-sector one-hot 行业暴露。它生成合成收益时植入了相同结构，所以能演示恢复过程。

## 3.3 如何估计因子收益？

每期横截面回归：

$$
\hat f_t=(X_t^TW_tX_t)^{-1}X_t^TW_tr_t,
$$

$W_t$ 常为市值权重或稳健权重。真实实施中，还会采用行业约束、稳健回归、极端收益处理，降低小股票或异常点的影响。

本项目用岭回归版本
$$
\hat f_t=(X^TX+\gamma I)^{-1}X^Tr_t
$$
避免小样本演示中的共线和数值不稳。截距在代码中加入，以免强迫所有系统性收益被暴露解释。

## 3.4 从因子收益到风险预测

收集滚动窗口内 $\hat f_t$，估计 $F$。也可对最近数据赋更高权重（指数加权），或对特征值收缩。残差 $u_{i,t}$ 的时间序列方差估计为 $D_{ii}$。真实模型还会考虑：新股的贝叶斯收缩、特异风险相关性、事件风险、国家/货币因子和波动率 regime。

## 3.5 为什么 Barra 更适合主动权益组合？

它允许直接写进投资政策的约束，例如：

$$
|x^T X_{\text{Value}}|\le0.10,\quad
|x^T X_{\text{Momentum}}|\le0.10,\quad
|\sum_{i\in s}x_i|\le0.05.
$$

这比“限制第 2 个 PCA 主成分”更容易解释。它也让业绩归因可以回答：本期收益来自价值倾斜、行业配置，还是特异选股？

## 3.6 风险模型 ≠ 预测模型

风险模型里的 value/momentum 暴露不表示你必然看多 value/momentum；它表示组合对这些共同波动来源敏感。你可使用 value alpha，同时将 value 风险暴露限制在较小区间：这是“赚取选股信号、控制系统性风险”的典型做法。

## 3.7 常见实施陷阱

- 把当日收盘后才发布的财报当作当日可知信息（未来函数）；
- 未处理行业虚拟变量与截距的共线性；
- 用 OLS 让极端回报或微盘股主导因子收益；
- 只看样本内拟合，不看风险预测的样本外校准；
- 忽略指数调仓、财报披露、限售解禁等事件特异风险。
