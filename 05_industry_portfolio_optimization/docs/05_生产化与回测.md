# 5. 生产化、回测与归因

## 5.1 生产系统比“一个优化脚本”多什么？

一个可审计的生产链路通常包含：

```text
版本化数据快照 -> 特征/模型版本 -> 风险与成本快照 -> 优化 -> 预交易合规
-> OMS/算法交易 -> 成交回报 -> 持仓核对 -> PnL 与风险归因 -> 模型监控
```

每个调仓日应能重放：当时股票池是什么、当时可见的财务数据是什么、用哪版 alpha 和参数、为什么某笔交易被下单或被拦截。

## 5.2 回测最低标准

- **点时数据**：只使用当时已知的价格、财报、指数成分与分类；
- **幸存者控制**：包含后来退市/被并购的证券；
- **可交易性**：停牌、涨跌停、最小交易单位、借券、ADV、冲击与延迟；
- **滚动重估**：每个调仓日仅使用过去窗口估计 alpha/risk，不可全样本 PCA；
- **组合级而非信号级**：信号好不代表加上约束和成本后组合仍好。

## 5.3 归因的基本框架

当采用 Barra 风格模型时，主动收益可概念性拆成：

$$
R_{active}\approx (X^Tx)^T f + \sum_i x_i u_i - \text{cost}.
$$

可报告行业、风格、特异选股、交易成本四块。风险归因也可用边际贡献或因子贡献。PCA 也能做风险分解，但“PC1 风险贡献”通常不如“Value 风险贡献”便于投资经理解释。

## 5.4 模型监控指标

- alpha：IC、分层收益、衰减、覆盖率、缺失率、预测分布漂移；
- risk：预测波动与实现波动、因子收益异常、残差风险变化、协方差条件数；
- execution：预测成本与实现成本、成交率、冲击、参与率；
- portfolio：换手、集中度、约束绑定频率、风险预算使用率。

本教学项目只演示一个调仓截面；真实回测应在每个调仓日运行相同流程并拼接结果。
