# 0. 组合优化全流程总览

## 0.1 核心思想：把“看多什么”与“害怕什么”分开

主动量化组合的输入至少分成两组：

- **Alpha / 预期收益 $\alpha$**：你认为哪些股票未来会跑赢；来源可为价值、动量、分析师预期、另类数据或机器学习模型。
- **风险模型 $\Sigma$**：哪些股票会一起涨跌、押注了哪些共同风险。它不应由 alpha 代替。

优化器通过权衡 $\alpha$ 与风险、成本和约束来决定主动权重 $x=w-b$，其中 $w$ 为目标权重、$b$ 为基准权重。

## 0.2 本项目的数学目标

本项目求解一个相对基准的 long-only 主动组合：

$$
\max_w\quad \alpha^T(w-b)-\lambda_r(w-b)^T\Sigma(w-b)
-\lambda_{tc}\sum_i c_i|w_i-w_i^{old}|
-\lambda_{impact}\sum_i q_i(w_i-w_i^{old})^2.
$$

含义如下：

| 部分 | 业务含义 |
|---|---|
| $\alpha^T(w-b)$ | 希望获得的主动收益 |
| $(w-b)^T\Sigma(w-b)$ | 主动风险（tracking-error 的平方） |
| $c_i\lvert\Delta w_i\rvert$ | 线性成本，如佣金、买卖价差、税费近似 |
| $q_i\Delta w_i^2$ | 非线性冲击；流动性越差，交易越贵 |

注意：优化器的单位必须一致。这里 alpha、协方差、成本都使用“单期（例：月度）收益率”单位；真实系统中通常每日优化，但风险和预测会使用不同持有期、不同年化尺度，必须转换一致。

## 0.3 从原始数据到权重

| 环节 | 输入 | 输出 | 本项目对应 |
|---|---|---|---|
| 股票池 | 上市、流动性、价格、可借券等 | 可交易股票集合 | 合成 40 只股票 |
| Alpha | 特征、标签、模型 | 预期超额收益、置信度 | `build_alpha()` |
| 风险模型 | 历史收益 / 基本面暴露 | $\Sigma$ | PCA 或 Barra 风格 |
| 成本 | ADV、点差、波动率、持仓 | 交易成本参数 | `linear_cost`、`impact_cost` |
| 优化 | 所有上述输入 | 目标权重 $w$ | `solve_active_portfolio()` |
| 交易 | 权重、价格、资金 | 股数 / 订单 | `trade_weight`（教学简化） |
| 独立检查 | 最终权重和模型输入 | 约束、风险、暴露报告 | `build_report()` |

## 0.4 为什么不直接最大化预测收益？

如果只最大化 $\alpha^Tw$，所有资金会涌向少数预测最高的股票。即使你加了单票上限，也常出现：行业集中、风格暴露极端、交易过多、预测误差被放大。均值—方差优化同样会把协方差估计误差放大，因此行业实践常使用：

1. 对 alpha 做 winsorize、标准化、行业中性化和置信度缩放；
2. 用稳健的因子风险模型替代纯样本协方差；
3. 对成本和换手显式惩罚；
4. 用硬约束控制不能违反的风险预算；
5. 优化后用另一套逻辑独立检查，而不是相信求解器状态即可。

## 0.5 PCA 与 Barra 各自扮演什么角色？

- **PCA**：从历史收益中找出解释方差最大的统计共同波动方向。构建快、适合探索和降噪；但主成分的经济含义与稳定性不保证。
- **Barra 风格模型**：先定义可解释的风格（大小盘、价值、动量、波动率等）和行业，再用横截面回归估计因子收益。适用于风险预算、合规沟通和归因，但数据清洗、因子定义和回归稳健性要求更高。

这并非“PCA 预测收益、Barra 控制风险”的固定分工：两者都是**风险端**的选择。本项目中的 alpha 单独构造。
