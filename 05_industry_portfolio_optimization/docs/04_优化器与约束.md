# 4. 优化器与约束：把研究观点变成可执行交易

## 4.1 为什么需要相对基准优化？

多数主动权益产品不是持有现金的绝对收益策略，而是相对某指数评估。因此，先定义 $x=w-b$ 很重要：行业、风格、tracking error 都围绕主动部分衡量。代码中组合仍满足 $\sum w=1$ 和 long-only，但允许小幅偏离基准。

## 4.2 本项目的约束

| 约束 | 数学形式 | 避免的问题 |
|---|---|---|
| 全额投资 | $\sum_iw_i=1$ | 无意留下现金 / 杠杆 |
| Long-only | $w_i\ge0$ | 不可借券或产品限制 |
| 单票上限 | $w_i\le6\%$ | 单一名称风险 |
| 主动单票限制 | $\lvert w_i-b_i\rvert\le3\%$ | 极端偏离基准 |
| 行业主动限制 | $\lvert\sum_{i\in s}(w_i-b_i)\rvert\le5\%$ | 行业押注 |
| 风格主动限制 | $\lvert X_k^T(w-b)\rvert\le0.10$ | 无意风格 beta |
| 换手上限 | $\sum_i\lvert w_i-w_i^{old}\rvert\le35\%$ | 不可执行、成本过高 |

硬约束用于“绝不能越界”的规则；软惩罚用于连续权衡。例如交易成本不只设上限，而是在目标函数中让每笔交易付出代价。

## 4.3 成本模型是如何简化的？

线性项 $c_i|\Delta w_i|$ 可理解为点差、手续费等。二次项 $q_i\Delta w_i^2$ 描述“订单越大、冲击越高”；真实常以交易额 / ADV、日内曲线、临时/永久冲击、交易参与率等拟合。这里让低流动性股票拥有更高的 $c_i,q_i$。

成本必须和仓位、持有期单位一致。若使用股数或美元交易额，模型也要相应转换。

## 4.4 求解后为什么还要独立检查？

优化软件说“optimal”只说明它解了你写出的数学问题；它不会发现你把行业标签、单位、成交量或基准对齐错了。`build_report()` 不读取求解器的约束对象，而是重新用 pandas/numpy 计算：预算、最小/最大权重、换手、行业偏离、风格暴露、预估主动风险、预估成本。这是生产工作流必须保留的一道防线。

## 4.5 常见坏结果与诊断

- **权重卡在上限**：alpha 太尖锐、风险/成本太弱，或约束太紧。
- **几乎不交易**：alpha 单位太小、成本单位太大，或上一期组合已满足最优。
- **行业偏离很大**：行业约束漏掉空行业、基准权重与股票池不一致。
- **求解失败**：协方差不半正定、约束不可行，或数值尺度差异过大。

可优先检查 `outputs/constraint_check.csv` 与 `portfolio_report.csv`。
